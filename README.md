# Services

**Category**: Boot2Root
**Difficulty**: Medium

Whole lot of services. Gain domain admin privileges and recover the flag at `C:\Users\administrator.SERVICES\Desktop\flag.txt`. Good luck.

Windows Defender is on for this box, and no defense evasion is needed for the intended route.

The file issued is an `.ova` file with size well over 10GB. Hence Google Drive link will be issued [here](https://drive.google.com/drive/folders/1QPzv8aNa1bP4KshbqZe9PNZ-VvGfEVlh?usp=sharing) for participants to host it locally on their machine.

Within the Google Drive link, a VM setup guide is provided. Additionally, a step by step bypass for Google Drive error of exceeded download quota is also issued.
